# 🚀 RefactorIQ — Intelligent Code Modernization Engine

> **Analyze. Refactor. Optimize.**
>
> RefactorIQ is an AI-powered software intelligence platform that helps engineering teams identify technical debt, visualize code architecture, and automate large-scale refactoring with confidence.

---

## 📖 Overview

Modern codebases grow increasingly complex over time, resulting in technical debt, hidden dependencies, and declining developer productivity.

**RefactorIQ** provides a comprehensive solution by combining architectural analysis, automated refactoring, security validation, and ROI tracking into a single intelligent platform.

---

## ✨ Key Features

### 📡 Architecture Intelligence
- Repository-wide dependency mapping
- Interactive visualization of file relationships
- Complexity hotspot detection
- Real-time topology analysis

### 🤖 Autonomous Refactoring Engine
- AI-generated code improvements
- Side-by-side patch previews
- Refactoring confidence scoring
- Safe and explainable code transformations

### 🛡️ Security & Quality Guardrails
- Dead code detection
- Orphaned import identification
- Circular dependency analysis
- Static code quality checks

### 📊 Technical Debt Analytics
- Zombie code detection
- Bloat line metrics
- Maintainability scoring
- Repository health monitoring

### 💰 Engineering ROI Tracker
- Development hours saved estimation
- Cost reduction analytics
- Productivity impact visualization
- INR-based value conversion

### 💬 Natural Language Code Assistant

Ask questions like:

```bash
Which modules have the highest technical debt?
```

```bash
Show circular dependencies in the auth service.
```

```bash
Suggest refactoring opportunities for this repository.
```

## 🎨 Design Philosophy

RefactorIQ follows a **Cognitive Typography System** designed to reduce developer fatigue and improve information scanning.

| Typography | Purpose |
|------------|----------|
| Slab Serif | Headings & metrics |
| Sans Serif | Main interface content |
| Monospace | Logs, code blocks, terminal output |
| Serif | Secondary navigation & labels |
| Script | Brand identity accents |

## 🏗️ System Architecture

```text
Repository
    │
    ▼
┌─────────────────┐
│ Ingestion Layer │
└─────────────────┘
    │
    ▼
┌─────────────────┐
│ Code Analysis   │
│ (Tree-Sitter)   │
└─────────────────┘
    │
    ▼
┌─────────────────┐
│ AI Refactoring  │
│ Agents          │
└─────────────────┘
    │
    ▼
┌─────────────────┐
│ Visualization   │
│ (React Flow)    │
└─────────────────┘
```

### Workflow

1. **Ingestion** → Scan repository structure and dependencies.
2. **Analysis** → Detect complexity, redundancy, and technical debt.
3. **Refactoring** → Generate AI-powered code improvements.
4. **Visualization** → Display optimized architecture and metrics.

## 🚀 Getting Started

### Prerequisites

- Node.js v18+
- npm, yarn, or pnpm

### Installation

```bash
git clone https://github.com/Lovishka/RefactorIQ.git
cd RefactorIQ
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
